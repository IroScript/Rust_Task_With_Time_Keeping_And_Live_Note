## Gemini CLI যা করেছে — ব্যর্থতার পোস্টমর্টেম

**১ম ভুল — `ui.push_id()` wrapper দিয়ে return type ভেঙেছে:**
Gemini `render_quote_card`-এর পুরো body-কে `ui.push_id(id, |ui| { ... })` দিয়ে wrap করেছে। এতে function-টি `egui::Response` return করার বদলে `()` return করতে শুরু করে। ফলে main loop-এ `card_response.clicked()` কাজ করা বন্ধ হয়ে যায় — editing feature সম্পূর্ণ মৃত।

**২য় ভুল — `show_rows` nested scroll তৈরি করেছে:**
Gemini বাইরের `ScrollArea::vertical()` এর ভেতরে আরেকটি `ScrollArea::show_rows()` বসিয়েছে। egui-তে nested ScrollArea without fixed pixel height = inner area collapses, শুধু প্রথম card দেখায়।

**৩য় ভুল — `bg_resp` interaction layer বারবার ভুল জায়গায় সরিয়েছে:**
`scroll_bg_drag` কে bottom-এ নিলে cards-এর উপরে z-order-এ বসে — সব click absorb করে ফেলে। Top-এ রাখলে scroll সমস্যা। এটা একাধিকবার আগপিছ করেছে।

**৪র্থ ভুল — duplicate code path মুছে দিয়েছে:**
`is_being_edited` এর দুটো branch (ScrollArea ভেতরে + বাইরে) এর একটা মুছেছে — hover-edit, character selection tracking, omni-drag handle সব উড়ে গেছে।
