## পাওয়া Bug গুলো এবং Fix সমূহ

### Bug 1 — Text Invisible at Any Scale < 100% (Root Cause)
```
d.remove::<egui::scroll_area::State>()  ← প্রতি frame এ এটা call হচ্ছে
```
এটা ScrollArea এর `content_size` মুছে ফেলছে → পরের frame-এ ScrollArea ভাবছে content = 0px → height collapse → text দেখা যাচ্ছে না।

**Fix**: শুধু `offset.y = 0.0` reset করো, পুরো State মুছবে না:
```rust
// আগের ভুল কোড:
d.remove::<egui::scroll_area::State>(id.with("scroll_main"));

// সঠিক কোড:
if let Some(state) = d.get_temp_mut::<egui::scroll_area::State>(scroll_id) {
    state.offset.y = 0.0;  // শুধু offset reset, content_size অক্ষত
}
```
Sub text scroll এর জন্যও same fix apply করতে হবে।

### Bug 2 — 10% Scale-এ Card খুব বড় দেখাচ্ছে
**Root cause**: `desired_rows = ((20.0 * card_scale).ceil() as usize).max(1)` এ scale 0.1 দিলে = `ceil(2.0) = 2`। TextEdit 2 rows minimum চায়। কিন্তু এই `desired_rows` শুধু TextEdit-এর minimum height। ScrollArea `max_height` দিয়ে capped হওয়া উচিত।

আসল সমস্যা: `allocate_ui_with_layout`-এর ভেতরে যদি কোনো widget unexpected space নেয় (যেমন TextEdit internal margin), তাহলে outer cursor বেশি advance করে।

**Fix**: `desired_rows = 1` সবসময়, এবং TextEdit-এ `.margin(Vec2::ZERO)` যোগ করো:
```rust
let dynamic_rows = 1usize;  // always minimum

egui::TextEdit::multiline(&mut edit_text)
    .desired_rows(dynamic_rows)
    .margin(Vec2::ZERO)  // ← এটা add করো — internal padding সরাবে
    // ...
```

### Bug 3 — Line Gap কাজ করছে না
`layout_quote_text` এ `TextFormat` এ `line_height: None` ছিল (default)। `main_line_gap` stored কিন্তু apply হচ্ছিল না।

**Fix** (already applied in file):
```rust
fn layout_quote_text(
    ...
    line_gap: f32,   // ← নতুন parameter (0.0–50.0)
) {
    let line_height_px = default_size * (0.98 + line_gap.clamp(0.0, 50.0) * 2.02 / 50.0);
    
    egui::TextFormat {
        font_id: ...,
        color: ...,
        line_height: Some(line_height_px),  // ← এখন apply হচ্ছে
        ..Default::default()
    }
}
```

Gap mapping:
| Gap Value | Line Height | Effect |
|---|---|---|
| `0.0` | `0.98×` font | Lines overlap 2% |
| `0.5` | `1.0×` font | Lines just touching |
| `5.0` | `~1.18×` font | Normal spacing |
| `50.0` | `3.0×` font | Very spacious |
