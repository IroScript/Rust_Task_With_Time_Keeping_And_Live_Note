# Card Height Scale System — সম্পূর্ণ Fix Guide (AI Coding Prompt)

---

## 🔍 Root Cause Analysis

কোডে `render_quote_card()` ফাংশনে এই লাইনগুলো সমস্যা তৈরি করছে:

```rust
let card_max_height = 450.0 * card_scale;
let card_min_height = 120.0 * card_scale;  // এটা 0% এ 0 হয়
```

কিন্তু `egui::ScrollArea`, `TextEdit::multiline(..).desired_rows(20)`, এবং `ui.allocate_ui_with_layout()` — এগুলোর নিজস্ব minimum intrinsic height আছে। `desired_rows(20)` একা-ই অনেক height নেয়। `ScrollArea` এর `auto_shrink([false, false])` জিনিসটা shrink হতে দেয় না। তাই 0% এ card কখনো সত্যিকারের 0px হয় না।

1. TextEdit::multiline().desired_rows(20) forces large intrinsic height
