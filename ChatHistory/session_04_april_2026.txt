Chat #9: Auto-Focus Implementation for Plus Button
========================================
সময়: ০৪/০৪/২০২৬ - দুপুর

Problem:
--------
Plus button click করার পরে user কে আবার input field এ click করতে হচ্ছিল।
এটা slow process এবং bad UX।

User Expectation:
-----------------
Plus button click → Directly type on keyboard
No extra click needed!

Solution Implemented:
---------------------
১. New State Field:
   - request_main_text_focus: bool
   - Track করে কখন auto-focus করতে হবে

২. Set Focus Request:
   - TitleBarAction::AddCardClicked handler এ
   - Keyboard Plus key handler এ
   - request_main_text_focus = true set করা হয়

৩. Auto-Focus Logic:
   - main_text_input TextEdit render করার পরে
   - if state.request_main_text_focus check করে
   - r.request_focus() call করে
   - state.request_main_text_focus = false reset করে

৪. Implementation Location:
   - File: src/main.rs (line ~4682-4700)
   - Panel এর main text input section এ

Code Flow:
----------
1. User clicks Plus button (or presses Plus key)
2. New blank card created at index 0
3. editing_quote_index = Some(0)
4. request_main_text_focus = true
5. Next frame: TextEdit renders
6. Auto-focus triggered: r.request_focus()
7. Cursor ready in input field
8. User can immediately type!

Build Status:
-------------
✅ Build successful (2m 34s)
✅ No errors
✅ Auto-focus working

User Experience Now:
--------------------
✅ Click Plus button
✅ Cursor automatically in input field
✅ Start typing immediately
✅ No extra click needed
✅ Fast and smooth workflow!

Testing:

Chat #18: Live Preview - Bidirectional Cursor Sync
========================================
সময়: ০৪/০৪/২০২৬ - রাত

User Clarification:
-------------------
"Live preview মানে card-এ যেখানে লিখছেন, সেই cursor position টা input field-এও দেখাবে এবং vice versa। Card এবং input field উভয় জায়গায় cursor একই position-এ থাকবে।"

Understanding:
--------------
Live Preview = Bidirectional Cursor Synchronization
- Card → Input Field: Card-এ cursor move করলে input field-এও same position-এ cursor দেখাবে
- Input Field → Card: Input field-এ cursor move করলে card-এও same position-এ cursor দেখাবে
- Real-time sync: Typing করার সময় cursor position continuously sync হবে

Implementation:
---------------

১. Card Main Text → Input Field Cursor Sync:
```rust
// LIVE PREVIEW: Sync cursor position from card to input field
if out.response.has_focus() && !is_new_quote {
    if let Some(cursor_state) = egui::TextEdit::load_state(ui.ctx(), edit_id) {
        if let Some(cursor_range) = cursor_state.cursor.char_range() {
            let cursor_pos = cursor_range.primary.index;
            
            // Sync cursor position to input field
            let input_field_id = egui::Id::new("main_text_edit_unique");
            if let Some(mut input_state) = egui::TextEdit::load_state(ui.ctx(), input_field_id) {
                input_state.cursor.set_char_range(Some(egui::text::CCursorRange::one(
                    egui::text::CCursor::new(cursor_pos)
                )));
                input_state.store(ui.ctx(), input_field_id);
            }
        }
    }
}
```

২. Input Field Main Text → Card Cursor Sync:
```rust
// LIVE PREVIEW: Sync cursor from input field to card
if r.has_focus() {

                }
            }
        }
    }
}
```

-------------

5. Set the same cursor position
6. Store the updated state
7. This happens every frame when either field has focus
