Chat #5: Button Background Hover Effect
========================================
সময়: ০৪/০৪/২০২৬ - সকাল

সমস্যা:
--------
আগের fix এ button এর text color change হচ্ছিল, কিন্তু background color change হচ্ছিল না।
User চাইছিল hover করলে button এর background color change হোক।

সমাধান:
--------
১. Button Background Hover Implementation:
   - Button তৈরি করার সময় fill(Color32::TRANSPARENT) দিয়েছি
   - stroke(egui::Stroke::NONE) দিয়ে border remove করেছি
   - Button response পাওয়ার পর .hovered() check করেছি
   - Hover হলে ui.painter().rect_filled() দিয়ে background draw করেছি

২. Hover Background Colors:
   - Main Data Stream: Color32::from_rgba_premultiplied(0, 255, 255, 30) - Cyan with 30 alpha
   - Auxiliary Data Stream: Color32::from_rgba_premultiplied(100, 255, 100, 30) - Lime with 30 alpha
   - Border radius: 2.0 (rounded corners)

৩. Button Spacing:
   - ui.spacing_mut().item_spacing.x = 4.0 যোগ করেছি
   - Button গুলোর মধ্যে 4px gap

৪. Code Structure:
   ```rust
   let resp = ui.add(
       egui::Button::new(egui::RichText::new("A+").color(NEON_CYAN).size(12.0))
           .fill(Color32::TRANSPARENT)
           .stroke(egui::Stroke::NONE)
   );
   if resp.hovered() {
       let rect = resp.rect;
       ui.painter().rect_filled(rect, 2.0, Color32::from_rgba_premultiplied(0, 255, 255, 30));
       clicked_on_controls = true;
   }
   ```

৫. Files Modified:
   - src/main.rs
   - Main Data Stream buttons (A+, ●, A-)
   - Auxiliary Data Stream buttons (A+, ●, A-)

--------
✅ Hover করলে button এর background cyan/lime color হয়
✅ Background semi-transparent (alpha 30)
✅ Rounded corners (2.0 radius)
✅ Text color fixed (NEON_CYAN / NEON_LIME)
✅ Build successful (1m 59s)
