Chat #9: Auto-Focus Implementation for Plus Button
========================================
সময়: ০৪/০৪/২০২৬ - দুপুর

Problem:
--------
Plus button click করার পরে user কে আবার input field এ click করতে হচ্ছিল।
এটা slow process এবং bad UX।

User Expectation:
-----------------
Plus button click → Directly type on keyboard
No extra click needed!

Solution Implemented:
---------------------
১. New State Field:
   - request_main_text_focus: bool
   - Track করে কখন auto-focus করতে হবে

২. Set Focus Request:
   - TitleBarAction::AddCardClicked handler এ
   - Keyboard Plus key handler এ
   - request_main_text_focus = true set করা হয়

৩. Auto-Focus Logic:
   - main_text_input TextEdit render করার পরে
   - if state.request_main_text_focus check করে
   - r.request_focus() call করে
   - state.request_main_text_focus = false reset করে

৪. Implementation Location:
   - File: src/main.rs (line ~4682-4700)
   - Panel এর main text input section এ

Code Flow:
----------
1. User clicks Plus button (or presses Plus key)
2. New blank card created at index 0
3. editing_quote_index = Some(0)
4. request_main_text_focus = true
5. Next frame: TextEdit renders
6. Auto-focus triggered: r.request_focus()
7. Cursor ready in input field
8. User can immediately type!

Build Status:
-------------
✅ Build successful (2m 34s)
✅ No errors
✅ Auto-focus working

User Experience Now:
--------------------
✅ Click Plus button
✅ Cursor automatically in input field
✅ Start typing immediately
✅ No extra click needed
✅ Fast and smooth workflow!

Testing:
